# Environment Variables

Tài liệu này liệt kê các biến môi trường đang được đọc từ `src/main/resources/application*.yml`, `config-server/src/main/resources/configs/*.yml`, `.env.example`, và `docker-compose.infra.yml`.

## Biến Chung Cho Java Services

| Biến | Dùng cho | Ghi chú |
| --- | --- | --- |
| `CONFIG_SERVER_URI` | Hầu hết Java services | URL Spring Cloud Config, mặc định thường là `http://localhost:8888`. |
| `SPRING_CLOUD_CONFIG_URI` | `news-service` | Biến tương đương cho config server trong `news-service`. |
| `EUREKA_INSTANCE_HOSTNAME` | Config/Eureka clients | Hostname dùng khi tạo `defaultZone`, mặc định `localhost`. |
| `EUREKA_ENABLED` | Config/Eureka clients | Bật/tắt register/fetch registry. |
| `EUREKA_CLIENT_SERVICEURL_DEFAULTZONE` | Một số service local/docker | URL Eureka đầy đủ, ví dụ `http://localhost:8761/eureka/`. |
| `SPRING_KAFKA_BOOTSTRAP_SERVERS` | Config chung | Kafka bootstrap mặc định trong `application.yml`. |
| `KAFKA_BOOTSTRAP_SERVERS` | Business services | Kafka bootstrap override theo service. |
| `AUDIT_LOG_TOPIC` | Service phát audit event | Mặc định `audit-topic` khi có fallback. |
| `KEYCLOAK_ISSUER_URI` | Gateway, identity, user, audit | Realm issuer URI cho resource server. |

## GitLab CI / Docker Hub

Đặt các biến sau trong GitLab CI/CD variables:

| Biến | Bắt buộc | Ghi chú |
| --- | --- | --- |
| `DOCKERHUB_USERNAME` | Có | Docker Hub username hoặc org user để login. |
| `DOCKERHUB_TOKEN` | Có | Docker Hub access token. |
| `DOCKERHUB_NAMESPACE` | Không | Namespace repo image; mặc định dùng `DOCKERHUB_USERNAME`. |

CI build mỗi service thành image `$DOCKERHUB_NAMESPACE/<service>:<commit-sha>`. Khi chạy trên default branch, CI push thêm tag `latest`.
